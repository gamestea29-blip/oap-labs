## Завдання 1 — `task1.cpp`

### Постановка
Розв'язати рівняння `ax² + bx + c = 0` для дійсних коефіцієнтів.

### Гілки та особливі випадки
1. `a = 0`, `b = 0`, `c = 0` — будь-яке `x` є розв'язком.
2. `a = 0`, `b = 0`, `c != 0` — коренів немає.
3. `a = 0`, `b != 0` — лінійне рівняння, `x = -c/b`.
4. `a != 0`, `D < 0` — дійсних коренів немає.
5. `a != 0`, `D = 0` — один корінь.
6. `a != 0`, `D > 0` — два корені.

Для порівняння з нулем використовується допуск `1e-9`. Ввід перевіряється; у разі помилки програма завершується з кодом 1.

### Трасування для `a=1, b=-3, c=2`
| Крок | Обчислення / перевірка | Результат |
|---|---|---|
| 1 | Перевірка вводу | Успішно |
| 2 | `a` дорівнює нулю? | Ні |
| 3 | `D = b² - 4ac = 9 - 8` | `D = 1` |
| 4 | `D > 0`? | Так |
| 5 | `x1 = (3 - 1)/2`, `x2 = (3 + 1)/2` | `x1=1`, `x2=2` |

### Тести
| Ввід `a b c` | Очікуваний результат | Яку гілку перевіряє |
|---|---|---|
| `1 -3 2` | два корені: 1.0000 і 2.0000 | `D > 0` |
| `1 2 1` | один корінь: -1.0000 | `D = 0` |
| `1 0 1` | дійсних коренів немає | `D < 0` |
| `0 2 -4` | лінійний корінь: 2.0000 | `a=0`, `b!=0` |
| `0 0 0` | будь-яке x | `a=0`, `b=0`, `c=0` |
| `0 0 5` | коренів немає | `a=0`, `b=0`, `c!=0` |
| `abc` | повідомлення про помилку вводу | неправильний ввід |

## Завдання 2 — `task2.cpp`, варіант 13

### Постановка
Межі: `a = -2`, `b = 1`.

Функція задається частинами:
- якщо `x < -2`: `f1(x) = 1/(x+1)`;
- якщо `-2 <= x <= 1`: `f2(x) = e^(x²)`;
- якщо `x > 1`: `f3(x) = sqrt(x²-4)`.

Перед обчисленням перевіряється коректність введення та область визначення обраної функції.

### Особливі випадки
- У першій гілці знаменник не повинен дорівнювати нулю. Точка `x=-1` не належить першій гілці, оскільки `-1` лежить між `-2` і `1`; тому ділення на нуль у цій гілці фактично недосяжне.
- У третій гілці потрібно `x²-4 >= 0`. Оскільки ця гілка має умову `x>1`, значення `1<x<2` не належать області визначення кореня. Наприклад, при `x=1.5` підкореневий вираз від'ємний — програма виводить помилку та завершується з кодом 1.
- Межі `x=-2` і `x=1` належать другій гілці.
- Неправильний числовий ввід завершує програму з кодом 1.

### Псевдокод
1. Ввести `x`; якщо ввід некоректний — повідомити про помилку та завершити програму.
2. Якщо `x < -2`, вибрати гілку 1, перевірити знаменник `x+1`, обчислити `1/(x+1)`.
3. Інакше, якщо `x <= 1`, вибрати гілку 2 та обчислити `exp(x*x)`.
4. Інакше вибрати гілку 3; перевірити `x*x-4 >= 0`, обчислити квадратний корінь.
5. Вивести `x`, номер гілки та `y` з чотирма знаками після коми.

### Трасування — по одному значенню з кожної гілки
| Вхід `x` | Умова / гілка | Обчислення | Результат |
|---|---|---|---|
| `-3` | `x < -2`, гілка 1 | `1/(-3+1) = -0.5` | `y=-0.5000` |
| `0.5` | `-2 <= x <= 1`, гілка 2 | `e^(0.5²) = e^0.25` | `y=1.2840` |
| `2.5` | `x > 1`, гілка 3 | `sqrt(2.5²-4) = sqrt(2.25)` | `y=1.5000` |

### Тести та межі умов
| Ввід `x` | Очікуваний результат | Яку гілку / випадок перевіряє |
|---|---|---|
| `-3` | гілка 1, `-0.5000` | перша гілка |
| `-2` | гілка 2, `e^4 = 54.5982` | ліва межа включена |
| `0.5` | гілка 2, `1.2840` | середина другої гілки |
| `1` | гілка 2, `2.7183` | права межа включена |
| `1.5` | помилка: від'ємний підкореневий вираз | третя гілка, поза областю визначення |
| `2.5` | гілка 3, `1.5000` | коректне значення третьої гілки |
| `abc` | помилка вводу | перевірка `std::cin` |

**Приклад помилки без перевірки:** для `x=1.5` умова `x>1` обирає третю гілку, але `x²-4 = -1.75`. Виклик `sqrt(-1.75)` для дійсного типу дає `NaN`. Тому перевірка області визначення необхідна.

## Завдання 3 — `task3.cpp` (додаткове)

### Постановка
За кодом тарифу, кількістю хвилин і використаними GB обчислити загальну вартість.

| Код | Абонплата, UAH | Хвилини включено | GB включено |
|---|---:|---:|---:|
| 1 | 100 | 100 | 5 |
| 2 | 200 | 300 | 10 |
| 3 | 300 | 500 | 20 |
| 4 | 400 | 1000 | 40 |

Перевищення тарифу: 1 UAH за хвилину та 20 UAH за GB. Менше використання не зменшує абонплату.

### Алгоритм
1. Зчитати код тарифу, хвилини та GB; перевірити ввід і межі.
2. За допомогою `switch` вибрати абонплату та включені обсяги.
3. Для невідомого коду вивести помилку й завершити програму з кодом 1.
4. Додати оплату за перевищення хвилин і GB.
5. Вивести суму з двома знаками після коми.

### Контрольний тест
Ввід: `2 350 12`.

Розрахунок: `200 + (350-300)*1 + (12-10)*20 = 290.00 UAH`.
