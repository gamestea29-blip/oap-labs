### Мета роботи
Навчитися складати програму для табулювання функції однієї змінної з використанням циклу `for` та перевірки області визначення функції.

### Завдання
Побудувати таблицю значень функції:

\[
y = \ln(2-x) + x^2
\]

Параметри: `a = -2`, `b = 2`, `h = 0.5`. Кількість значень — 9. Для обчислення використовується натуральний логарифм.

### Алгоритм (псевдокод)
1. Задати `a = -2`, `b = 2`, `h = 0.5`.
2. Для `i` від 0 до 8 обчислити `x = a + i * h`.
3. Перевірити, чи `2 - x > 0`.
4. Якщо умова не виконується, вивести `undefined`.
5. Інакше обчислити `y = ln(2 - x) + x * x` і вивести результат з точністю до чотирьох знаків після коми.

### Результати табулювання

| i | x | y |
|---:|---:|---:|
| 0 | -2.0000 | 5.3863 |
| 1 | -1.5000 | 3.5028 |
| 2 | -1.0000 | 2.0986 |
| 3 | -0.5000 | 1.1663 |
| 4 | 0.0000 | 0.6931 |
| 5 | 0.5000 | 0.6555 |
| 6 | 1.0000 | 1.0000 |
| 7 | 1.5000 | 1.5569 |
| 8 | 2.0000 | undefined |

### Перевірка обчислень

- Для `x = -2`: `y = ln(2 - (-2)) + (-2)^2 = ln(4) + 4 = 5.3863`.
- Для `x = 0`: `y = ln(2) + 0^2 = 0.6931`.
- Для `x = 2`: `2 - 2 = 0`, а натуральний логарифм нуля не визначений, тому результат — `undefined`.

### Трасування

**Допустимий аргумент `x = 0`:**
- `2 - x = 2`, умова `2 > 0` виконується.
- `y = ln(2) + 0² = 0.6931`.

**Недопустимий аргумент `x = 2`:**
- `2 - x = 0`, умова `0 > 0` не виконується.
- Виводиться `undefined`.

### Компіляція та запуск
Компілятор: GCC (g++), стандарт C++17.

Команда компіляції:
```bash
g++ -std=c++17 -Wall -Wextra -pedantic task1.cpp -o task1
```

Запуск:
```bash
./task1
```
