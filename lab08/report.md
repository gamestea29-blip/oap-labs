# Лабораторна робота № 8
## Табулювання функції двох змінних (вкладені цикли)

**Виконав:** Олійник Святослав  
**Група:** 21КІ  
**Варіант:** 13

### Мета роботи
Навчитися табулювати функцію двох змінних за допомогою вкладених циклів `for` та перевіряти область визначення перед обчисленням.

### Завдання
Для варіанта 13 задано функцію:

\[
z(x,y) = \frac{x^2+1}{x+y+1}
\]

Формула визначена за умови `x + y + 1 ≠ 0`. Значення `x` і `y`: `-1`, `-0.5`, `0`, `0.5`, `1`. Крок — `0.5`. Рядки відповідають `x`, стовпці — `y`.

### Алгоритм (псевдокод)
1. Задати початкове значення `-1.0` та крок `0.5`.
2. Надрукувати заголовок із п'ятьма значеннями `y`.
3. Зовнішнім циклом перебрати п'ять значень `x`.
4. Для кожного `x` внутрішнім циклом перебрати п'ять значень `y`.
5. Обчислити знаменник `x + y + 1`.
6. Якщо знаменник дорівнює нулю, надрукувати `undefined`; інакше обчислити та надрукувати `z`.
7. Після кожного рядка перейти на новий рядок.

### Таблиця результатів

| x \ y | -1.0000 | -0.5000 | 0.0000 | 0.5000 | 1.0000 |
|---:|---:|---:|---:|---:|---:|
| -1.0 | -2.0000 | -4.0000 | undefined | 4.0000 | 2.0000 |
| -0.5 | -2.5000 | undefined | 2.5000 | 1.2500 | 0.8333 |
| 0.0 | undefined | 2.0000 | 1.0000 | 0.6667 | 0.5000 |
| 0.5 | 2.5000 | 1.2500 | 0.8333 | 0.6250 | 0.5000 |
| 1.0 | 2.0000 | 1.3333 | 1.0000 | 0.8000 | 0.6667 |

### Контрольні обчислення

- `f(-1, -1) = (1 + 1) / (-1 - 1 + 1) = -2.0000`.
- `f(0, 0) = (0 + 1) / (0 + 0 + 1) = 1.0000`.
- `f(1, 1) = (1 + 1) / (1 + 1 + 1) = 0.6667`.

Приклад недопустимої клітинки: `x = -1`, `y = 0`, тоді `x + y + 1 = 0`, тому виводиться `undefined`.

### Трасування переходу між рядками

| Зовнішній цикл | x | Дія |
|---:|---:|---|
| 0 | -1.0 | Обчислюються п'ять значень для y від -1.0 до 1.0 |
| 1 | -0.5 | Після завершення попереднього рядка починається новий рядок |
| 2 | 0.0 | Внутрішній цикл знову перебирає всі п'ять значень y |

### Компіляція та запуск
Компілятор: GCC (`g++`), стандарт C++17.

Команда компіляції:
```bash
g++ -std=c++17 -Wall -Wextra -pedantic task1.cpp -o task1
```

Запуск:
```bash
./task1
```
