## 1. Мета роботи

Підготувати середовище розробки C++, скомпілювати та запустити демонстраційну програму-візитівку, перевірити роботу компілятора з різними стандартами C++ та зафіксувати приклад помилки компіляції.

## 2. Використані інструменти

| Інструмент | Версія / відомості |
|---|---|
| Компілятор g++ | 16.2.0 (MSYS2 UCRT64) |
| Стандарт C++17 | `__cplusplus = 201703` |
| Стандарт C++98 | `__cplusplus = 199711` |
| Редактор | Visual Studio Code (версію не зафіксовано на наданих скриншотах) |
| GDB | Встановлено; окремий скриншот успішного проходження налагодження не надано |

## 3. Код програми

Основний файл роботи: `main.cpp`. Програма виводить ім'я студента, групу, номер варіанта, назву/версію компілятора та значення макросу стандарту C++.

## 4. Результати перевірок

### 4.1. Компіляція та запуск із g++ у режимі C++17

Використана команда компіляції:

```powershell
g++ -std=c++17 -Wall -Wextra main.cpp -o main.exe
```

Команда запуску:

```powershell
.\main.exe
```

На скриншоті `02_run_cpp17.png` зафіксовано виведення даних студента та `standard 201703`. На скриншоті `01_build_success_vscode.png` зафіксовано успішне завершення завдання збірки у VS Code.

### 4.2. Перевірка стандарту C++98

Використана команда:

```powershell
g++ -std=c++98 -Wall -Wextra main.cpp -o main98.exe
```

Запуск:

```powershell
.\main98.exe
```

На скриншоті `04_run_cpp98.png` зафіксовано успішний запуск і значення `standard 199711`.

### 4.3. Точка зупину

На скриншоті `03_breakpoint_set.png` видно встановлену точку зупину біля `return 0;`. Цей скриншот підтверджує встановлення breakpoint, але не підтверджує повний успішний сеанс налагодження (зупинку виконання під GDB).

### 4.4. Приклад помилки компіляції

Для перевірки було тимчасово прибрано крапку з комою після інструкції виведення `Variant: 13`. На скриншоті `05_gpp_missing_semicolon_error.png` компілятор g++ повідомляє:

```text
error: expected ';' before 'std'
```

Після фіксації помилки крапку з комою потрібно повернути до `main.cpp` та зберегти виправлений файл. У цьому архіві `main.cpp` уже містить правильний варіант коду.
