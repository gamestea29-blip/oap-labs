## Завдання 1. Характеристики трикутника

### Постановка задачі
За трьома сторонами трикутника `a`, `b`, `c` обчислити:
- півпериметр: `p = (a + b + c) / 2`;
- площу за формулою Герона: `S = sqrt(p * (p-a) * (p-b) * (p-c))`;
- радіус вписаного кола: `r = S / p`;
- радіус описаного кола: `R = a*b*c / (4*S)`;
- висоту до сторони `a`: `h = 2*S / a`.

Результати вивести таблицею з двома знаками після коми.

### Псевдокод
1. Ввести `a`, `b`, `c`.
2. Обчислити півпериметр `p`.
3. Обчислити площу `S` за формулою Герона.
4. Обчислити `r`, `R` та `h`.
5. Вивести всі результати з двома знаками після коми.

### Таблиця тестів

| Тип тесту | Вхідні дані (a, b, c) | Очікуваний результат |
|---|---|---|
| Контрольний | 3, 4, 5 | p=6.00; S=6.00; r=1.00; R=2.50; h=4.00 |
| Додатковий | 5, 5, 6 | p=8.00; S=12.00; r=1.50; R=3.25; h=4.80 |

## Завдання 2. Обчислення формули (варіант 13)

### Постановка задачі
Обчислити значення виразу:

**s = ∛(x² + y²) + tg(z/2)**

Для тригонометричної функції `tan` аргумент задається в радіанах.

### Обмеження на вхідні дані
- Кубічний корінь визначений для будь-якого дійсного числа.
- Тангенс `z/2` не визначений, коли `cos(z/2) = 0`, тобто `z/2 = π/2 + kπ`, де `k` — ціле число.
- Інших обмежень на `x` та `y` формула не має.

### Псевдокод
1. Ввести `x`, `y`, `z`.
2. Обчислити `sumOfSquares = x*x + y*y`.
3. Обчислити `cubeRootPart = cbrt(sumOfSquares)`.
4. Обчислити `tangentPart = tan(z/2)`.
5. Обчислити `s = cubeRootPart + tangentPart`.
6. Вивести `x`, `y`, `z` і `s` з чотирма знаками після коми.

### Таблиця тестів

| Тип тесту | Вхідні дані (x, y, z) | Очікуваний результат |
|---|---|---|
| Контрольний | 2, 3, 1 | s ≈ 2.8976 |
| Межовий | 0, 0, 0 | s = 0.0000 |

## Завдання 3. Середні значення (додаткове)

### Постановка задачі
Для трьох введених чисел `a`, `b`, `c` обчислити:
- середнє арифметичне: `(a+b+c)/3`;
- середнє геометричне: `cbrt(a*b*c)`;
- середнє гармонічне: `3/(1/a + 1/b + 1/c)`.

### Обмеження на вхідні дані
Для середнього гармонічного числа `a`, `b`, `c` мають бути ненульовими, а сума `1/a + 1/b + 1/c` не повинна дорівнювати нулю. Кубічний корінь визначений і для від'ємного добутку.

### Псевдокод
1. Ввести `a`, `b`, `c`.
2. Обчислити середнє арифметичне.
3. Обчислити кубічний корінь із добутку `a*b*c`.
4. Обчислити суму обернених значень і середнє гармонічне.
5. Вивести три результати з чотирма знаками після коми.

### Таблиця тестів

| Тип тесту | Вхідні дані (a, b, c) | Очікуваний результат |
|---|---|---|
| Контрольний | 1, 2, 4 | 2.3333; 2.0000; 1.7143 |
| Межовий | 1, 1, 1 | 1.0000; 1.0000; 1.0000 |

## Висновок

Під час лабораторної роботи створено лінійні програми мовою C++17. Використано тип `double`, введення `std::cin`, виведення `std::cout` та форматування за допомогою `std::fixed`, `std::setprecision` і `std::setw`. Із бібліотеки `<cmath>` використано `std::sqrt`, `std::cbrt` і `std::tan`. Контрольні та додаткові тести дали очікувані результати. Також враховано обмеження формул, зокрема недопустимість ділення на нуль і точок, у яких тангенс не визначений.
