# Лабораторна робота № 6
## Циклічно-розгалужені алгоритми

**Виконав:** Олійник Святослав  
**Група:** 21КІ  
**Варіант:** 13

### Мета роботи
Навчитися використовувати цикл `for`, умовне розгалуження та лічильники для обробки набору цілих чисел.

### Завдання
Ввести ціле число `n`, а потім `n` цілих температур у градусах Цельсія. Порахувати кількість температур у трьох категоріях:

- `below` — температура нижча за `L`;
- `inside` — температура від `L` до `H` включно;
- `above` — температура вища за `H`.

Для варіанта 13: `L = -15`, `H = 15`. Допустимі значення: `1 ≤ n ≤ 30`, `-100 ≤ t ≤ 100`.

### Алгоритм (псевдокод)
1. Задати константи `L = -15` та `H = 15`.
2. Зчитати `n`. Якщо введення некоректне або `n` не належить діапазону від 1 до 30, вивести `Error` і завершити програму з кодом 1.
3. Створити лічильники `below`, `inside`, `above` зі значенням 0.
4. Виконати цикл `for` рівно `n` разів:
   - зчитати температуру `t`;
   - якщо читання не вдалося або `t` поза межами від -100 до 100, вивести `Error` і завершити програму з кодом 1;
   - якщо `t < L`, збільшити `below`;
   - інакше якщо `t ≤ H`, збільшити `inside`;
   - інакше збільшити `above`.
5. Після успішного введення всіх температур вивести три лічильники.

### Трасування першого тесту

Ввід:
```text
4 -16 -15 15 16
```

| Температура | Перевірка | Лічильники (below / inside / above) |
|---:|---|---|
| -16 | `-16 < -15` | 1 / 0 / 0 |
| -15 | `-15` входить у межі | 1 / 1 / 0 |
| 15 | `15` входить у межі | 1 / 2 / 0 |
| 16 | `16 > 15` | 1 / 2 / 1 |

Результат:
```text
below / inside / above = 1 / 2 / 1
```

### Перевірки

| Ввід | Очікуваний результат | Фактичний результат |
|---|---|---|
| `4 -16 -15 15 16` | `below / inside / above = 1 / 2 / 1` | `below / inside / above = 1 / 2 / 1` |
| `1 -15` | `below / inside / above = 0 / 1 / 0` | `below / inside / above = 0 / 1 / 0` |
| `0` | `Error`, код 1 | `Error`, код 1 |
| `1 101` | `Error`, код 1 | `Error`, код 1 |
| `1 abc` | `Error`, код 1 | `Error`, код 1 |
| `1` і завершення вводу (EOF) | `Error`, код 1 | `Error`, код 1 |

Для правильного вводу сума трьох лічильників дорівнює `n`.

